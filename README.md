## 🛠️ Getting Started

To work with any specific project in this repository:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/aniruddh209/All-Extra-Projects.git
   cd All-Extra-Projects
   ```

2. **Navigate into the desired project folder**:
   ```bash
   cd "<Project-Name>"
   ```

3. **Install dependencies**:
   - For Node.js / JavaScript projects:
     ```bash
     npm install
     ```
   - For Python projects:
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     pip install -r requirements.txt
     ```
   - For .NET projects:
     ```bash
     dotnet restore
     dotnet build
     ```

4. **Environment Setup**:
   - Check if an `.env.example` file exists in the project folder. If so, copy it:
     ```bash
     cp .env.example .env
     ```
   - Fill in your local configuration / API keys.
